# 🇧🇩 Hello Bangladesh

A simple beginner-friendly web development project built with **HTML5 and CSS3**.

The project displays a clean webpage featuring the text **"Hello Bangladesh 🇧🇩"** and was created to practice the fundamentals of HTML and CSS.





## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- 🇧🇩 Hello Bangladesh landing page
- 🎨 Custom styling with CSS
- 📱 Simple responsive layout
- 🔗 External CSS stylesheet
- 🧑‍💻 Beginner-friendly project structure
